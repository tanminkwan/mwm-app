# [MWM] 미들웨어관리소: GenAI 기반 미들웨어 관리 자동화 및 지능형 리포팅 시스템 구축 보고서

## 1. 목적 / 배경
본 프로젝트인 **MWM(Middleware Management System, 일명 '미들웨어관리소')**는 복잡해지는 기업 내 미들웨어(WAS, WEB) 및 IT 자산의 관리 효율성을 극대화하기 위해 시작되었습니다. 기존의 미들웨어 관리는 수동 점검과 개별 설정 파일의 직접 확인에 의존하여, 휴먼 에러 발생 가능성이 높고 변경 이력 추적이 어렵다는 문제점이 있었습니다. 

특히 JEUS, WebToB와 같은 핵심 미들웨어의 인스턴스 상태를 실시간으로 모니터링하고, `domain.xml`이나 `http.m` 등 복잡한 설정 파일의 변경 사항을 자동으로 대사(Compare)하여 히스토리를 관리할 필요성이 대두되었습니다. 또한, 인프라의 복잡한 연결 관계를 시각화하고, 보안이 강화된 OIDC/OAuth2 기반의 통합 인증 체계를 구축하여 안정적이고 보안성이 높은 관리 환경을 제공하는 것을 최종 목표로 삼았습니다.

---

## 2. GenAI 활용 내용 및 수행 내용
본 프로젝트 개발 과정에서 **GenAI 코딩 어시스턴트(Antigravity)**를 전 단계에 걸쳐 적극적으로 활용하였습니다.

*   **프롬프트 설계 및 모델 선택**: 복잡한 아키텍처 설계와 보안 로직 구현을 위해 프로젝트의 전체 컨텍스트(Metadata, DB Schema, Spec Docs)를 AI에게 지속적으로 제공하는 프롬프트를 설계하였습니다. 최신 LLM 모델을 활용하여 Flask-AppBuilder의 커스텀 로직 및 SQLAlchemy의 복잡한 Relationship 구성을 최적화했습니다.
*   **구체적인 활용 방법**:
    1.  **백엔드 로직 자동화**: Flask-AppBuilder 기반의 데이터 모델링(`app/models/was.py`) 및 뷰 구성을 위해 AI를 활용하여 반복적인 CRUD 코드를 생성하고, DeepDiff 라이브러리를 활용한 설정 파일 비교 로직을 정교화했습니다.
    2.  **보안 및 인증 강화**: OIDC/OAuth2 서버 구현 시 `client_credentials` grant type 추가, mTLS 기반 브라우저 인증 로직 설계 등 고난도 보안 명세 구현에 AI의 가이드를 반영하였습니다.
    3.  **데이터 파이프라인 구성**: Agent로부터 수집된 비정형 텍스트 데이터를 정규표현식(Regex)을 통해 구조화된 JSON 데이터로 파싱하고 DB에 매핑하는 파이프라인을 AI와 함께 설계 및 검증하였습니다.
    4.  **고급 리포팅 엔진**: Mermaid 코드를 이미지로 자동 렌더링하고 S3(MinIO)와 연동하여 이메일 본문에 삽입하는 복잡한 리포팅 기능을 AI의 알고리즘 제안을 통해 구현하였습니다.
*   **결과물**: 실시간 대시보드, 자동 설정 대사 엔진, 시각화 다이어그램이 포함된 이메일 발송 시스템, 통합 IDP(Identity Provider) 서버.

## 3. 시사점 / Lesson's Learned / 향후 계획
*   **인사이트**: GenAI를 개발 파트너로 활용함으로써 단순 반복 업무(Boilerplate 코드 작성 등) 시간을 60% 이상 단축할 수 있었으며, 이를 통해 아키텍처 설계 및 보안 로직 검증과 같은 핵심적인 문제 해결에 더 집중할 수 있었습니다. 특히 복잡한 라이브러리(DeepDiff, Kroki) 연동 시 AI의 예제 코드 제공이 큰 도움이 되었습니다.
*   **아쉬운 점 및 한계**: AI가 프로젝트의 전체 비즈니스 맥락을 완벽히 이해하지 못할 경우, 때때로 현재 인프라 환경에 맞지 않는 범용적인 코드를 제안하는 경우가 있었습니다. 이를 극복하기 위해 명확한 제약 조건과 컨텍스트 전달의 중요성을 재확인하였습니다.
*   **향후 계획**: 
    1.  **AI 기반 장애 예측**: 수집된 미들웨어 로그와 상태 데이터를 기반으로 GenAI를 활용한 이상 징후 감지 및 장애 예측 모델을 도입할 계획입니다.
    2.  **자동 조치(Auto-Remediation)**: 단순 장애 상황 발생 시 AI가 해결 가이드를 제시하거나 표준화된 조치 스크립트를 자동 실행하는 기능을 추가하여 관리 효율을 더욱 높이고자 합니다.
    3.  **확장성**: 현재의 미들웨어 관리 엔진을 클라우드 네이티브 환경(Kubernetes 등)의 리소스 관리 영역으로 확장할 예정입니다.
