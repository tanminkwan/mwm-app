# 애플리케이션 내 라이브러리 탐색 기능 (Update Findings in App)

이 문서는 JEUS 목록(`WasModelView`)에서 제공하는 **"Update Findings in App"** 기능에 대해 설명합니다.

## 1. 기능 개요
**Update Findings in App** 기능은 선택된 WAS 도메인에 배포된 애플리케이션 파일들을 대상으로 특정 라이브러리(패턴)를 전수 조사하는 기능입니다. 주로 시스템 전체에 걸쳐 보안 취약점이 있는 라이브러리(예: Log4j)가 포함되어 있는지 확인하기 위해 사용됩니다.

## 2. 주요 동작 원리
이 기능은 서버에 설치된 **MW 에이전트(MW Agent)**와 통신하여 실제 파일 시스템을 검색합니다.

1.  **대상 식별**: 사용자가 선택한 WAS 도메인에 연결된 모든 애플리케이션(`mw_application`) 정보를 데이터베이스에서 가져옵니다.
2.  **경로 추출**: 애플리케이션의 설치 경로(`application_home`)를 기반으로 검색 대상 디렉토리를 설정합니다.
3.  **에이전트 명령 발송**:
    *   서버의 OS 종류 및 기술 명세에 따라 적절한 에이전트 명령을 생성하여 발송합니다.
    *   현재 기본적으로 `*log4*.jar` 패턴을 검색하도록 설정되어 있습니다.

## 3. OS별 실행 명령 (MW Agent Command)

| OS 종류 | 에이전트 명령 ID | 검색 패턴 | 비고 |
| :--- | :--- | :--- | :--- |
| **Windows** | `EXE.FILTER4WIN` | `^.*log4.*.jar` | 정규표현식 기반 검색 |
| **HPUX** | `RUN.FILTER` | `*log4*.jar` | 셸 스크립트 기반 실행 |
| **기타 (Linux 등)** | `EXE.FILTER` | `*log4*.jar` | 표준 실행 명령 |

## 4. 활용 사례
*   **보안 취약점 전수 조사**: Log4j와 같은 공통 라이브러리의 취약점이 발견되었을 때, 운영 중인 모든 WAS의 애플리케이션 내에 해당 파일이 존재하는지 즉시 확인 가능합니다.
*   **라이브러리 버전 관리**: 특정 버전의 JAR 파일이 어디에 배포되어 있는지 추적할 때 유용합니다.

## 5. 소스 코드 위치
*   **View**: `app/views/was.py` 내 `WasModelView.callFilteredInfo`
*   **에이전트 연동**: `app/sqls/agent.py` 내 `insert_command_master`
